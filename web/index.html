Hollow Knight: Silksongweb port · iPad / mobile build

Play ▸ The game page. Streams the build in chunks into on-device storage (OPFS), never building the archive in RAM, then boots Unity. Loader self-test ▸ Checks what this device can do — OPFS, run-once caching, resume, chunk verification — and runs the real chunk pipeline with a synthetic dataset. Works without the game build.

This folder is the browser side of the port. It needs a Unity WebGL build of Silksong in web/Build/, prepared by the tools that live in web/tools/:

  • node web/tools/prepare-build.mjs --build <unity Build dir> — checks the build, drops junk, replaces the cutscenes with tiny black placeholders, chunks the data and wasm, and writes build-manifest.json.
  • node web/tools/verify-build.mjs — proves the chunks on disk are complete and match the manifest.
  • node web/tools/serve.mjs 8080 — serves this folder with the Range support and MIME types iOS Safari needs.

See web/IPAD.md for the iPad story and web/BUILD.md for the build pipeline.
